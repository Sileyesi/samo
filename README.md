# Samo

Браузер на движке Chromium (CEF 154), написанный на Rust. Классические горизонтальные вкладки, плавность уровня Zen и глубокая кастомизация через CSS.

Весь интерфейс (вкладки, тулбар, адресная строка, палитра, меню) — это HTML/CSS/JS в отдельном CEF-оверлее. Поэтому любую деталь можно перекрасить или переделать темой или `user.css`, без пересборки.

## Установка

Готовые сборки лежат в [Releases](https://github.com/Sileyesi/samo/releases):

- **Windows:** установщик `Samo-…-windows-x64-setup.exe` (права администратора не нужны) или portable `.zip`.
- **Linux:** `Samo-…-x86_64.AppImage` или `samo-…-linux-x86_64.tar.gz` → `./install.sh`. Установщик добавляет Samo в меню приложений с иконкой и ставит его в `~/.local/opt/samo`.

Собрать установщики самому: `scripts/package-linux.sh` (Linux) и `scripts/package-windows.ps1` (Windows, нужны MSVC, Ninja и Inno Setup). Релиз в CI собирается по тегу `v*` (`.github/workflows/release.yml`).

## Запуск из исходников

```bash
scripts/run.sh            # debug-сборка + запуск
scripts/run.sh --release  # оптимизированная сборка
```

При первой сборке крейт `cef` скачивает CEF 154.0.34 (~300 МБ) в `~/.local/share/cef`. Для сборки нужны `cmake` и `ninja`: их даёт локальный venv `.tools/` (`python3 -m venv .tools && .tools/bin/pip install cmake ninja`) или `sudo pacman -S cmake ninja`.

## Возможности

- **Вкладки.** Анимации открытия, закрытия, перетаскивания и закрепления на пружинных кривых из Zen. Ширина вкладок замораживается при закрытии мышью, как в Chrome: следующий крестик оказывается под курсором. Есть горизонтальный скролл при переполнении, индикаторы загрузки и звука, контекстное меню.
- **Адресная строка.** Подсказки из открытых вкладок, истории (frecency), закладок и поиска.
- **Палитра команд** (`Ctrl+T`). Плавающая панель по центру. `>` переключает на команды, `@tabs` ищет по вкладкам.
- **Compact mode** (`Ctrl+Alt+C`). Интерфейс прячется и выезжает поверх страницы при наведении на верхний край.
- **Цвет сайта.** Тулбар подкрашивается цветом `theme-color` активной страницы.
- **Прочее:** поиск по странице, split view (`Ctrl+Alt+V/H/U`), загрузки, запросы разрешений, восстановление сессии, `Ctrl+Shift+T`.
- **Темы:** 7 встроенных (Samo Dark/Light, Midnight, Frost, Dusk, Sakura, OLED) и свои в `~/.config/samo/themes/*.css`.
- **Внутренние страницы:** `samo://settings`, `samo://newtab`, `samo://history`, `samo://downloads`.

## Кастомизация

| Что | Где |
|---|---|
| Поведение, тема, плотность, скорость анимаций, шорткаты | `~/.config/samo/config.toml` или `samo://settings` |
| Своя тема | `~/.config/samo/themes/<id>.css` с переменными `--samo-*` (полный список — в `ui/shared/tokens.css`) |
| Любые правки интерфейса | `~/.config/samo/user.css` (селекторы `.samo-tab[active]`, `.samo-toolbar`, `.samo-urlbar` …) |

Все файлы перезагружаются на лету, перезапуск не нужен.

## Устройство

- `src/`: CEF-ядро — окно, оверлеи, вкладки, обработчики, схема `samo://`, API, шорткаты.
- `crates/services/`: конфиг, темы, история и закладки (SQLite), сессия, омнибокс, раскладка клавиш. Покрыто юнит-тестами.
- `ui/`: интерфейс браузера и внутренние страницы.
- `themes/`: встроенные темы.
- `docs/ANALYSIS.md`: UX-анализ Zen, Arc, Vivaldi, Chrome и Firefox с конкретными цифрами.
- `docs/ARCHITECTURE.md`: архитектура и контракт JS↔Rust.

## Инструменты разработки

- `cargo test -p samo-services`: юнит-тесты.
- `scripts/run.sh --remote-debugging-port=9229`, затем `node scripts/cdpshot.mjs out`: скриншоты всех вью через DevTools.
- `node scripts/demo.mjs out 9229`: визуальный тур (вкладки, палитра, настройки, темы).
- `ui/dev/chrome-dev.html`: интерфейс с моком API, для правки вёрстки в обычном браузере.

## Известные ограничения

- Одно окно: `Ctrl+N` открывает вкладку.
- Индикатор звука видит только `<audio>`/`<video>` в главном фрейме.
- Попапы `window.open` открываются вкладками, поэтому OAuth-окна, которые общаются с opener, могут не работать.
- `beforeunload`-диалоги не показываются.
